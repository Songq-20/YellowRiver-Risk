# Demo Dataset

This directory contains a lightweight toy dataset designed for rapid functionality testing and verifying workflow reproducibility during peer review.

## Contents

- `demo_DNA_virus.fasta`: 50 representative DNA viral contigs subsampled from the environmental metagenomic assemblies.
- `demo_RNA_virus.faa`: 50 representative RNA viral RdRp ORF amino acid sequences subsampled from the environmental assemblies.
- `demo_MAG.fasta`: A representative metagenome-assembled genome (MAG) subsampled from the environmental assemblies.
